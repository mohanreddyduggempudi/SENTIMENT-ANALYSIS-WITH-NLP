# DESCRIPTION OF TASK : SENTIMENT ANALYSIS USING NLP

This project focuses on building a Sentiment Analysis model using Natural Language Processing (NLP) and Machine Learning techniques. The main aim of the project is to analyze movie reviews and classify them as Positive or Negative based on the text entered by the user. Sentiment Analysis is widely used in industries to understand customer opinions, feedback, and emotions from textual data.

In this project, the IMDb Movie Reviews Dataset was used for training and testing the machine learning model. The dataset contains thousands of movie reviews labeled with positive and negative sentiments. Python programming language was used for implementing the complete project along with libraries such as Pandas, Scikit-learn, and Matplotlib.

Initially, the dataset was loaded and processed using Pandas. The review text and sentiment labels were separated into input and output variables. Since machine learning algorithms cannot directly understand text data, TF-IDF Vectorization was used to convert textual data into numerical format. TF-IDF helps in identifying important words present in the reviews and assigns weights to them based on their frequency and importance.

After preprocessing, the dataset was split into training and testing sets using train_test_split(). Logistic Regression was used as the machine learning algorithm for classification. The model learns patterns from the dataset and predicts whether the review sentiment is positive or negative.

The project also includes performance evaluation using Accuracy Score, Classification Report, and Confusion Matrix. These evaluation metrics help in understanding the efficiency and prediction capability of the model.

An additional interactive feature was implemented where users can enter their own movie reviews through the terminal. The trained model processes the entered review and predicts the corresponding sentiment. For example, reviews containing words such as “excellent”, “amazing”, and “great” are usually predicted as Positive, while reviews containing words like “worst”, “terrible”, and “bad” are predicted as Negative.

This project demonstrates the practical implementation of Natural Language Processing and Machine Learning techniques for text classification problems. It provides knowledge about text preprocessing, feature extraction, model training, prediction, and evaluation. Overall, the system successfully performs sentiment prediction with good accuracy and shows how NLP can be used for analyzing human language and opinions effectively.
